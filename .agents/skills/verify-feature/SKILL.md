# Feature Verification

After implementation:

1. Run the relevant tests.
2. Run the build.
3. Run linting if available.
4. Test the changed functionality.
5. Check for regressions.
6. Fix any failures.
7. Repeat verification until successful.
8. Report exactly what commands were run and their results.

Do not declare the task complete without verification.
