# Feature Planning

1. Read intent.md.
2. Read spec.md.
3. Read AGENTS.md.
4. Inspect the existing codebase.
5. Identify affected files.
6. Identify dependencies.
7. Identify risks.
8. Identify tests.
9. Create or update plan.md.
10. Do not modify source code.

The plan must be detailed enough that another developer could implement it without seeing this conversation.
