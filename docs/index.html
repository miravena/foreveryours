ForeverYours

The companion the family briefs — your voice in Dad's day when you can't be there.

A voice-first AI companion for older adults. A caregiver briefs it once — names, preferences, daily updates — and the senior gets a warm, low-friction voice conversation that actually uses that context, while the caregiver gets honest safety flags, never silent surveillance.

How it works

HEAR (speech-to-text) → fast-path safety check (rule-based, instant, no API key needed) → RECALL (memory search, scoped by what the caregiver briefed) → THINK (open-weight NVIDIA model via Nebius Token Factory, streamed) → SPEAK (streamed text-to-speech) → AUDIT (background safety re-check) + memory extraction

Run it yourself

Two ways to try it: the terminal demo (three scripted beats) or the browser demo (one page, record your voice, hear the reply). Full details in README.md and CONTRIBUTING.md.

git clone https://github.com/miravena/foreveryours.git
cd foreveryours
sudo apt-get install -y espeak-ng   # local text-to-speech needs this on Linux
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env                # fill in NEBIUS_API_KEY -- see README "Nebius access"

# terminal demo:
.venv/bin/python main.py beat1
.venv/bin/python main.py beat2
.venv/bin/python main.py beat3
.venv/bin/python main.py day2      # proves memory survives a separate process run

# browser demo:
.venv/bin/python webapp.py          # then open http://localhost:7860

Both work without a Nebius key too — a distress/confusion phrase still gets the immediate, rule-based safety reassurance; it just can't continue the fuller conversation past that point without a real model call.
