# Plan: Issue 63 (Test Integrity)

## The Bug
Benchmark 9 ("Circadian Agency & Night Mode Compliance") in `tests/test_mature_benchmarks.py` was making a live API call to the LLM on every CI run. To prevent the CI pipeline from failing when no real API key is present, it used a blanket `except Exception:` block to catch the failure and `skipTest`. 
This is dangerous because it swallows *any* exception (e.g., `SyntaxError`, `NameError`, `RuntimeError`) during the `stream_reply` loop, meaning developers could introduce fatal Python crashes into `stream_reply`, and Benchmark 9 would silently convert them into "skipped" tests, hiding the broken build.

## The Fix
1. Remove the live API call from Benchmark 9 entirely.
2. Use `@patch("pipeline.think.get_client")` to mock the Nebius client response, completely removing the `except Exception:` block.
3. Assert that the prompt successfully generated by `stream_reply` includes the `"NIGHT MODE"` instructions.
4. Provide a gentle mock response and assert that the benchmark loop correctly parses it and asserts on the required string vocabulary (e.g., `"here for you"` and not `"go to sleep"`).

## Verification
Run `python -m unittest tests.test_mature_benchmarks` locally to ensure Benchmark 9 executes successfully without hitting the network and without skipping.
