# Hackathon rules (snapshot)

**Snapshot taken 2026-10-04** from <https://nebiusglobalaihackathon.devpost.com/rules> (Nebius x
NVIDIA Global AI Hackathon, run by Devpost). The operative sections are copied here so we can
work offline and diff against them; the rules are not expected to change. **The Devpost page
is authoritative.** Left out: eligibility detail, IP/release, publicity, liability, disputes and
personal-information boilerplate (sections 3, 7, 9-15). How these map to our work:
[`ROADMAP.md`](ROADMAP.md) ("Judging requirements" and "How entries are judged"). Our tracks and
tasks live on GitHub, not here.

- **Submission Period:** Wed 2026-08-26 9:00 am PT to **Fri 2026-10-30 10:00 am PT** (17:00 UTC).
- **Judging Period:** Tue 2026-12-01 9:00 am PT to Tue 2026-12-15 12:00 pm PT.

## 4. Project requirements

**What to create:** a working software application that runs on either Nebius Token Factory or
Nebius AI Cloud and uses at least one NVIDIA open source model, and that fits one of the four
tracks. We are in the **Personal AI** track.

- **Personal AI Track:** build an always-on, private assistant that works for you while keeping
  your data under your control. Give it persistent memory, reusable skills, access to the tools
  and information you choose, and the ability to carry out tasks across your daily workflows.
  Use at least one NVIDIA open source model, and tools such as NVIDIA NemoClaw, OpenShell,
  Hermes Agent and Nebius Serverless.
- Other tracks (not ours): Coding and Agentic Engineering; Best Apps and Agents; Physical AI.
- **Third-party integrations:** you must be authorized to use any third-party SDK, API or data
  under its terms.

## 4. Submission requirements

1. A Project built with the required developer tools that meets the project requirements.
2. **A URL to a working demo, hosted application, or test build.**
3. **A text description** of the features and functionality.
4. **A URL to a public code repository** (GitHub, GitLab or Bitbucket) that contains all source,
   assets and instructions needed to be functional. It must be public and open source with a
   license file (Apache 2.0, MIT, MPL 2.0, ...) **detectable and visible in the repo's About
   section.**
5. **A README** with setup instructions and clear guidance for running the project.
6. **Highlight how you used NVIDIA Nemotron or other NVIDIA open source models, where Token
   Factory accelerated your workflow, and any other Nebius tools or services used.**
7. **A demonstration video:**
   - **less than 3 minutes** (judges need not watch past 3 minutes);
   - shows the Project functioning on the device it was built for;
   - **uploaded and publicly visible on YouTube**, with the link on the submission form;
   - **no third-party trademarks or copyrighted music/material** unless you have permission.
8. **Identify which track** you are submitting into.
9. **Provide feedback on Nebius Token Factory, AI Cloud and any NVIDIA tools, models or
   technologies used.** (Completing the feedback section is what makes an entry eligible for the
   Most Valuable Feedback prize.)
10. If the Project existed before the Submission Period, a written explanation of what was
    significantly updated during it.

**Multiple submissions:** allowed, but each must be unique and substantially different.

**Testing:** access must be provided to the working Project for judging and testing via a
website, functioning demo, or test build. If it is private, include login credentials in the
testing instructions. **The Entrant must make the Project available free of charge and without
any restriction for testing, evaluation and use by the Sponsor, Administrator and Judges until
the Judging Period ends.** Judges are not required to test it and may judge on the text,
images and video alone.

**Language:** all materials in English (or with an English translation).

**Team representation:** a team must appoint and authorize one individual (the
"Representative") to represent, act and enter the Submission on its behalf. The Representative
must meet the eligibility requirements.

**Ownership:** the Submission must be your (or your team's) original work, solely owned, and not
violate others' IP or privacy rights. Open source use is allowed if you comply with the licenses
and build on it.

## 5. Submission modifications

You may save **draft** versions on Devpost before the Submission Period ends. **After it ends you
may not change the Submission**, though you may keep updating the Project in your Devpost
portfolio. The Sponsor/Devpost may permit post-deadline edits only to remove material that
infringes a mark/right, discloses personal information, or is otherwise inappropriate.

## 6. Judges and criteria

**Stage One (pass/fail):** the Project reasonably fits the theme and reasonably applies the
required APIs/SDKs. It fits the theme if it is a genuine attempt at the track's stated goal, not
a superficial rebrand of an unrelated idea.

**Stage Two:** all Submissions that pass Stage One are scored on these **equally weighted**
criteria, at the judges' sole and absolute discretion:

1. **Technological Implementation:** how well the project is built, and how effectively it
   uses Nebius Token Factory or AI Cloud model(s) and NVIDIA Nemotron or other NVIDIA open
   source models as part of the solution.
2. **Design:** does the project deliver a complete, coherent product experience, not just a
   technical proof of concept?
3. **Potential Impact:** does it make a credible, specific case for solving a real problem for a
   real audience, and does the solution actually address it based on what is demonstrated?
4. **Quality of the Idea:** is it a creative, non-obvious use of Nebius and NVIDIA models, and
   does the team show genuine understanding of the problem space?

**Tie-break:** tied Submissions are compared on the first criterion above, then the next, and so
on; if still tied, the panel of Judges votes.

**Feedback Submissions** are evaluated on completeness, viability and potential impact.
